작동 방식

3단계면 끝. 터미널 몰라도 됩니다.

무거운 건 전부 PC가 합니다. 폰은 리모컨이에요.

1

PC에서 실행

받은 프로그램을 더블클릭. 주소·코드·비밀번호 카드가 뜹니다. (PC엔 Claude Code만 한 번 로그인해 두면 끝)

2

폰에서 연결

모바일 데이터로도 OK. 카드의 주소를 열고 코드 + 비밀번호 입력하면 내 PC와 바로 연결돼요.

3

말로 시키고 미리보기

“이렇게 만들어줘” 채팅 → PC가 코드 생성 → 즉시 폰에 라이브 미리보기. 배포 대기 없음.

왜 좋은가

다른 “AI 앱빌더”와
근본부터 다릅니다.

클라우드에 내 코드를 올리지도, AI 요금을 따로 내지도 않아요.

≈ ₩0

AI·실행 비용이 내 PC, 내 Claude에서

코드 생성·빌드·미리보기가 전부 내 컴퓨터에서 돌아갑니다. 별도 AI 구독을 또 살 필요가 없어요.

⚡

즉시 라이브 미리보기

저장하자마자 폰 화면이 갱신. 배포 기다림이 없습니다.

📡

어디서나

집 PC는 켜두고, 밖에서 모바일 데이터로 폰만 있으면 연결돼요.

🗂️

여러 앱 동시에

프로젝트를 칩으로 전환하며 2~3개를 나란히 작업.

🔒

비밀번호 보호

내 연결은 비밀번호로 잠겨 있어 아무나 못 붙습니다.

💻

mac · Windows · Linux

어느 PC든 동작. 폰은 그냥 웹 링크라 설치도 필요 없어요.

🧠

진짜 Claude Code

장난감 모델이 아니라, 내 PC의 진짜 Claude가 만듭니다.

폰만 꺼내면 개발실.

지하철에서도, 카페에서도. 떠오른 생각을 말하면 PC가 만들어 둡니다.
