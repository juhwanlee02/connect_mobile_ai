# 고객용 설치 및 사용 가이드

## 1. 이게 뭔가요?

폰에서 Claude(AI)한테 명령을 내리면, PC가 자동으로 앱을 만들어주고, 결과를 폰 화면에서 바로 미리볼 수 있는 도구입니다.

---

## 2. 준비물 체크리스트

아래 3가지가 모두 갖춰져야 합니다. 하나라도 빠지면 실행되지 않습니다.

- [ ] **Node.js 20 이상** — [nodejs.org](https://nodejs.org) 에서 LTS 버전 다운로드 및 설치
- [ ] **cloudflared** — 폰과 PC를 인터넷으로 연결해주는 프로그램
  - **Mac:** 터미널에서 `brew install cloudflared`
  - **Windows:** PowerShell에서 `winget install cloudflare.cloudflared` 또는 [공식 다운로드 페이지](https://developers.cloudflare.com/cloudflared/install-and-setup/installation/)에서 설치 파일 다운로드
- [ ] **Claude Code 로그인 완료** — 터미널에서 `claude` 명령이 작동해야 합니다. 아직 설치하지 않았다면 `npm install -g @anthropic-ai/claude-code` 후 `claude login`으로 로그인

> **라이선스 키는 선택 사항입니다.** 키 없이도 **체험판(프로젝트 1개)** 으로 바로 실행할 수 있습니다. 여러 프로젝트가 필요하다면 판매자에게 구매한 키(`CPMC-XXXXXX-YY`)를 받아 등록하면 무제한으로 사용할 수 있습니다.

---

## 3. 설치

판매자에게 받은 폴더(ZIP 압축 해제 또는 GitHub clone)를 열고, 터미널에서 아래 명령을 실행합니다.

```bash
npm install
```

설치가 완료되면 다음 단계로 넘어갑니다.

---

## 4. 실행

### 체험판으로 바로 시작하기

라이선스 키 없이도 바로 실행할 수 있습니다. 체험판은 **프로젝트 1개**까지 무료로 사용할 수 있습니다.

### 방법 1 — 더블클릭 런처 (권장)

운영체제에 맞는 런처를 더블클릭합니다.
- **macOS:** `launchers/시작.command`
- **Windows:** `launchers/시작.bat`
- **Linux:** `launchers/시작.sh`

터미널 창이 열리고 잠시 기다리면 **공유 카드**가 표시됩니다. 폰에서는 화면 상단에 **🧪 체험판** 배너가 표시됩니다.

**여러 프로젝트가 필요하다면** 프로젝트 루트의 `license.txt` 파일에 구매한 라이선스 키를 붙여넣고 저장하세요. 이후 런처를 다시 실행하면 배너 없이 무제한으로 사용할 수 있습니다.

### 방법 2 — 터미널 명령 직접 입력

키 없이 체험판으로 실행:
```bash
npm start
```

구매한 키로 무제한 실행:
```bash
LICENSE_KEY=받은키 npm start
```

예시:
```bash
LICENSE_KEY=CPMC-ABC123-01 npm start
```

---

잠시 기다리면 터미널에 아래와 같은 **공유 카드**가 표시됩니다.

```
✅ 준비 완료! 폰에서 아래로 접속하세요

  주소:    https://xxxx-xxxx.trycloudflare.com
  아이디:   admin
  비밀번호: gT7kpQ
  ── 또는 이 링크 하나만 폰에서 열기(아이디 자동 입력) ──
  링크:    https://xxxx-xxxx.trycloudflare.com/#id=admin
  관리:    http://localhost:8080/setup?k=6f1a9c...
```

이 세 가지 정보(주소, 아이디, 비밀번호)를 이어지는 단계에서 사용합니다. 카드의 **링크**를 그대로
열면 아이디까지 자동으로 채워지니, 비밀번호만 입력하면 됩니다.

> **참고:** 이 터미널 창을 열어둬야 합니다. 닫으면 연결이 끊어집니다.

### 4-1. PC 설정 페이지 (처음 실행 시 자동으로 열림)

**맨 처음 실행**(아이디·비밀번호를 아직 정한 적이 없을 때)에는 위 카드가 뜨는 것과 별개로,
**PC 브라우저에 설정 페이지가 자동으로 열립니다.** 이 화면에서 아이디/비밀번호를 원하는 값으로
바꾸고, 화면의 **QR 코드**를 폰 카메라로 찍으면 아이디가 이미 입력된 로그인 화면이 바로 열려
비밀번호만 넣으면 접속됩니다.

이후 실행부터는 자동으로 열리지 않지만, 카드의 **`관리:`** 줄 주소를 PC 브라우저 주소창에
붙여넣으면 언제든 다시 열 수 있습니다. 이 페이지는 **이 PC에서만** 열리고(다른 PC나 폰의
터널 주소로는 접근 불가), 계정 변경 외에도 파이프라인 템플릿·산출물 서식(PRD 등)
설정을 여기서 편집할 수 있습니다. 자세한 내용은 [`README.md`의 "PC 설정 페이지(관리
UI)"](../README.md#-pc-설정-페이지-관리-ui) 절을 참고하세요.

## 5. 폰에서 사용하기

1. 폰 브라우저에서 공유 카드의 **링크**를 엽니다(또는 **주소**만 열고 아이디를 직접 입력해도 됩니다) → **아이디가 자동 입력**됩니다
2. 로그인 화면이 뜨면 **비밀번호**를 정확히 입력하고 **로그인**을 누릅니다 (아이디/비밀번호 칸에서 **Enter**로도 로그인됩니다)
3. 로그인되면 화면 상단에 **프로젝트 바**가 나타납니다. 처음에는 기본 프로젝트 `my-app`이 선택된 상태입니다.

> 💡 한 번 로그인하면, 같은 실행(같은 주소)에서는 탭을 닫았다 다시 열어도 **로그인 화면 없이 바로 홈**으로 들어갑니다. 다만 PC 프로그램을 껐다가 다시 켜면 주소가 새로 바뀌므로, 새 주소에서는 **처음 한 번만 다시 로그인**하면 됩니다(아이디·비밀번호 자체는 그대로 유지되니 값은 바뀌지 않습니다).
4. 명령 입력창에 작업을 입력합니다. 예를 들어:
   - `public/index.html을 커피숍 랜딩 페이지로 만들어줘`
   - `public/index.html에 파란색 버튼 추가해줘`
   - `public/style.css의 배경색을 흰색으로 바꿔줘`
5. 명령을 보내면 PC가 자동으로 작업하고, 완료되면 **미리보기가 즉시 갱신**됩니다

> **중요:** 명령할 때 반드시 `public/` 경로를 명시해야 합니다. 예: `public/index.html`, `public/style.css`

---

## 5-1. 여러 프로젝트 사용하기

프로젝트 바에서 **➕ 새 프로젝트** 버튼을 탭하면 영문/숫자로 된 프로젝트 이름을 입력하는 창이 뜹니다. 만들어진 프로젝트는 칩 형태로 프로젝트 바에 표시됩니다.

> **체험판 제한:** 체험판에서는 프로젝트를 1개만 만들 수 있습니다. 두 번째 프로젝트를 만들려고 하면 "체험판은 프로젝트 1개까지예요. 구매하면 무제한!" 메시지가 표시됩니다. 여러 프로젝트가 필요하다면 라이선스 키를 구매해 `license.txt`에 등록하세요.

- **프로젝트 전환:** 칩을 탭하면 해당 프로젝트의 로그와 미리보기로 전환됩니다.
- **동시 작업:** 여러 프로젝트를 동시에 빌드할 수 있습니다 (라이선스 키 필요). 단, 같은 프로젝트에 작업이 진행 중일 때 추가 명령을 보내면 거부됩니다.
- **각 프로젝트 독립:** 프로젝트마다 로그, 미리보기, 파일이 완전히 분리됩니다.

---

## 6. 종료

터미널에서 **Ctrl+C** 를 누르면 모든 프로그램이 종료됩니다.

주소(터널 URL)는 실행할 때마다 새로 만들어지므로, 다음에 실행하면 주소가 달라집니다. 매번 폰에서 새 주소로 접속해야 하며, 아이디·비밀번호는 그대로지만 새 주소에서는 처음 한 번 다시 로그인해야 합니다.

## 7. 자주 묻는 문제

| 증상 | 해결 방법 |
|------|-----------|
| 주소가 안 떠요 / 터널이 시작되지 않아요 | `cloudflared`가 설치되어 있는지 확인하고, 인터넷 연결 상태를 점검하세요 |
| 폰에서 연결이 안 돼요 | 아이디와 비밀번호를 공유 카드에 나온 그대로 정확히 입력했는지 확인하세요 |
| "아이디 또는 비밀번호가 올바르지 않아요"가 떠요 | 카드에 나온 아이디·비밀번호를 대소문자까지 정확히 입력했는지 확인하세요(링크로 열었다면 아이디는 자동 입력되니 비밀번호만 확인) |
| "PC에서 초기 설정을 먼저 완료해 주세요"가 떠요 | PC에서 `npm start`(또는 런처)가 아직 준비 중이거나 실패한 상태입니다. PC 터미널 창을 확인하세요 |
| "PC가 아직 준비되지 않았어요"가 떠요 | PC 쪽 프로그램이 막 켜졌거나 잠깐 재연결 중입니다. 몇 초 기다렸다가 다시 시도하세요. 계속 반복되면 PC 터미널 창이 켜져 있는지 확인하세요 |
| 명령을 보냈는데 페이지가 안 바뀌어요 | PC 터미널에서 `claude` 명령이 로그인된 상태인지 확인하고, 명령에 `public/` 경로를 명시했는지 확인하세요 |
| "체험판은 프로젝트 1개까지" 메시지가 나와요 | 체험판은 프로젝트 1개만 사용할 수 있습니다. 여러 프로젝트가 필요하면 판매자에게 라이선스 키를 구매한 뒤 `license.txt`에 붙여넣으세요 |
| 라이선스 키 오류가 나요 | `license.txt`에 키가 정확히 입력됐는지, 또는 `LICENSE_KEY` 환경변수에 오타가 없는지 확인하세요. `CPMC-XXXXXX-YY` 형식이어야 합니다 |
| 설정 페이지(`/setup`)가 안 열려요 / 접속이 거부돼요 | 이 페이지는 **PC 자신에서만** 열립니다. 카드의 `관리:` 주소를 그대로(키 포함) PC 브라우저에 붙여넣었는지 확인하세요. 폰이나 다른 PC에서 열면 항상 거부됩니다 |
