## 한 줄 요약

폰에서 Claude한테 시켜 앱을 만들고, 폰으로 미리보며 피드백하는 **모바일 개발 루프**를 누구나 쓰게 해주는 플랫폼. 무거운 작업(코드 실행·빌드·AI 요금)은 **전부 사용자 PC**에서 처리하고, 운영자는 **얇은 중계 서버**만 운영 → **원가 ≈ 0, 마진 좋은 구독 모델**로 수익화.

## 왜 이 방향인가 (핵심 결정)

- 클라우드에서 사용자 코드를 직접 돌리면(샌드박스) 제일 비싸고 위험함 → **버림**
- 대신 **사용자가 자기 PC에서 도구를 실행** → 무거운 작업이 전부 사용자 쪽
- 운영자는 **얇은 중계 서버**만 운영 → 싸고 안전, 마진 좋음
- AI 요금도 사용자가 자기 Claude 계정으로 부담 → 운영 원가 ≈ 0

## 3개 구성요소

### 1. 로컬 도구 (사용자 PC 설치) — **(가) CLI / 데몬**

- **기존 Claude Code 설치를 재사용**해 코드 생성 (사용자 로컬 인증 그대로 사용; 전제: 사용자가 Claude 구독자)
- 채팅 명령 받기 → 코드 생성 → 빌드 → **사용자 본인 Firebase 프로젝트에 배포**
- 중계 서버와 지속 연결(WebSocket) 유지
- 한 줄 설치·실행하는 명령형 데몬 (MVP 최단거리)

### 2. 중계 서버 (운영자가 호스팅) — **수익화 포인트**

- 폰 ↔ PC 메시지 **중계만** (코드 실행 안 함, 전달만 → 프라이버시)
- **페어링 세션** 단위로 연결 관리 (계정·로그인 없이 페어링 코드/QR로 연결)
- MVP에서는 결제 미구현. 단, **수익화 진입점(seam) 확보**:
  - "연결 = 페어링 세션"을 명확한 단위로 → 나중에 `plan/limit` 부착
  - 페어링 코드 발급 지점에 "동시연결 수 / 세션 길이" 체크 훅 자리 마련

### 3. 폰 웹앱 (PWA)

- 채팅으로 명령
- 폰 크기 프레임으로 미리보기 (배포된 Firebase URL 로드)
- 상태/로그 표시

## 미리보기 비용 분석 (왜 Firebase가 괜찮은가)

- 배포는 **사용자 본인 Firebase 프로젝트**로 나감 → 운영자 청구서엔 안 잡힘 (운영자 비용 0)
- 용도가 "개발 중 본인 폰 미리보기"라 트래픽은 개발자 1명뿐 → Firebase 무료(Spark) 한도(하루 전송 360MB) 안에서 끝남
- 유료(Blaze) 넘어가도 전송 $0.15/GB 수준 → 사실상 무시 가능
- 비용이 튀는 건 "완성 후 일반 사용자 수천 명 서비스" 단계인데, 이는 MVP 범위 밖 + 사용자가 결정할 영역

## 수익화 모델 — 구독제(Freemium SaaS)

수익원은 "연산"이 아니라 **연결·편의·안정성**. 원가 ≈ 0 → 마진 최고.

| 무료 (훅) | 유료 (월 구독) |
|---|---|
| PC 1대 연결 | PC 여러 대 / 멀티디바이스 |
| 기본 페어링 | 팀 공유 · 권한 관리 |
| 세션 길이 제한 | 무제한 세션 / 상시 연결 |
| 수동 배포 | 자동 배포 · 커스텀 도메인 |
| — | 푸시 알림 · 우선 중계 |

- **해자:** 직접 중계서버를 깔 수도 있지만, 대부분은 "그냥 켜지는 편의(폰앱+안정연결+푸시+터널)"에 돈을 냄 (Dropbox vs rsync 논리)
- **안 함:** 사용량 과금 — AI 요금을 이미 사용자가 내므로 반발 큼
- **나중 확장:** 팀/B2B 라이선스, 배포 호스팅 대행(원가 발생 → 별도 가격)

## 알려진 난관 / 주의점

- "폰으로 시키고 PC에서 실행"하려면 사용자 PC가 **켜져 있고 중계서버에 연결**돼 있어야 함 → 이 연결이 제품의 심장
- 보안: 중계 서버는 메시지만 전달하고 코드는 안 보게 설계 (프라이버시)
- 전제: 사용자 PC에 Claude Code가 설치·로그인돼 있고, Firebase CLI 사용 가능해야 함

## MVP 범위

우선 **"로컬 도구 ↔ 중계 ↔ 폰" 최소 연결 1개 동작**시키기:
1. PC에서 CLI 실행 → 페어링 코드 발급
2. 폰 웹앱에서 코드 입력 → 중계서버 통해 PC와 연결
3. 폰에서 명령 → PC가 Claude Code로 코드 생성·빌드·Firebase 배포
4. 폰에서 배포 URL 미리보기

결제·계정·멀티디바이스·팀기능·푸시·터널은 **MVP 이후** (seam만 확보).
