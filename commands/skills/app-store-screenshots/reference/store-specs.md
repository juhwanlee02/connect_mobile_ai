# Store image specs (2026)

## iOS — App Store Connect
- iPhone 6.9" (required): **1320 × 2868** (portrait) / 2868 × 1320 (landscape). Devices: iPhone 17/16 Pro Max.
  - Accepted alternates: 1290×2796, and 6.5" 1284×2778 / 1242×2688.
- iPad 13" (required if app runs on iPad): **2064 × 2752**. Alt 12.9": 2048×2732.
- Upload only the largest size per family; App Store Connect auto-scales down.
- App icon: **1024 × 1024**, PNG/JPEG, RGB, **no alpha**.
- Screenshots: PNG/JPEG, RGB, **no alpha channel**, 1–10 per device class. Exact pixels (1px off = rejected).

## Android — Google Play
- Phone screenshots: **1080 × 1920** recommended (9:16) / 1920×1080 (16:9). Min 2, max 8.
  - Each side 320–3840px; long side ≤ 2× short side; ≤ 8MB; JPEG or 24-bit PNG, no transparency.
- 7" tablet: 1080×1920+; 10" tablet: 1200×1920+; min 4 each if tablet supported.
- Feature graphic (required): **1024 × 500**, JPEG or 24-bit PNG, no alpha.
- App icon: **512 × 512**, 32-bit PNG (alpha allowed).
