현재 프로젝트에 **월 운영비 0원 · 온디바이스 우선** 제약을 적용해줘.

1. 프로젝트 루트에 `ARCHITECTURE_CONSTRAINTS.md`를 만들고 다음을 정본으로 기록한다.
   - 핵심 기능은 서버, Supabase, 외부 DB, 유료 API 없이 동작
   - 데이터는 SQLite/Isar/Hive/SharedPreferences 등 기기 내부에 저장
   - AI 기능은 실행 가능한 온디바이스 Flutter 패키지나 포함 가능한 경량 모델 우선
   - 클라우드가 꼭 필요하면 구현하지 말고 로컬 대체안을 제시
   - 월 고정 운영비 0원
   - 선택 예외: 전 세계 랭킹만 Firebase RTDB Spark 무료 요금제, 로컬 폴백 필수
2. `DEV_BRIEF.md`가 있으면 위 제약을 반영하고 상충하는 요구를 명시한다.
3. 이미 코드가 있으면 네트워크·백엔드·유료 SDK 의존성을 검사해 로컬 대체로 바꾼다.
4. 기능을 삭제해야 할 때는 임의로 삭제하지 말고 대체 기능과 이유를 사용자에게 보고한다.
5. 이후 기능 논의·구조·개발 단계는 `ARCHITECTURE_CONSTRAINTS.md`를 우선 입력으로 사용한다.
