앱 내에서 흑/백 테마를 전환할 수 있는 기능을 구현해줘.

[사전 분석 — 반드시 먼저 수행]
1. 앱의 모든 화면/위젯을 탐색하여 하드코딩된 색상값 목록 도출
2. 현재 상태관리 방식 파악 (setState, Provider, Riverpod 등)
3. 기존 다크/라이트 색상 패턴 파악 (배경, 텍스트, 카드, 테두리, 강조색 등)
4. 차트, 그래프, 커스텀 페인터 등 특수 영역의 색상도 확인

[요구사항]
- 상단 바 또는 설정에 테마 전환 아이콘 버튼 배치 (해/달 아이콘)
- 버튼을 누르면 다크 모드 ↔ 라이트 모드 즉시 전환
- 앱의 기존 상태관리 방식에 맞춰 앱 전체에 테마 반영
- 사용자의 테마 선택을 SharedPreferences로 저장하여 앱 재시작 시에도 유지

[다크 모드 색상 가이드]
- 배경: 어두운 색상 (#0D1117 계열)
- 텍스트: 밝은 색상 (흰색, #E6EDF3 계열)
- 카드/컨테이너: 배경보다 약간 밝은 색상 (#161B22 계열)
- 테두리: 미묘한 밝은 색상 (#21262D 계열)

[라이트 모드 색상 가이드]
- 배경: 밝은 색상 (#FFFFFF, #F6F8FA 계열)
- 텍스트: 어두운 색상 (#1F2328 계열)
- 카드/컨테이너: 배경보다 약간 어두운 색상 (#F0F0F0 계열)
- 테두리: 미묘한 어두운 색상 (#D1D9E0 계열)

[구현 방식]
- AppColors 또는 ThemeData 클래스에 다크/라이트 색상 정의
- 하드코딩된 색상을 모두 테마 참조 방식으로 교체
- 기존 앱의 상태관리 패턴에 따라 Provider/Notifier/등으로 테마 상태 관리

[주의사항]
- 모든 화면에서 배경과 텍스트의 대비가 충분해야 함 (가독성 최우선)
- 차트/그래프 영역도 테마에 맞게 배경색 전환
- 데이터 시각화 색상 (상승/하락, 긍정/부정 등)은 두 테마 모두에서 잘 보여야 함
- 버튼, 배지, 강조색 등도 테마에 맞게 조정
