## 체크리스트 (6항목)

*(소비: 개발(5단계) 완료 게이트)*

- [ ] **오프라인 persistence 활성화** — 재실행 시 캐시에서 읽어 read 과금을 방지한다.
      구현 근거: {{item_1_evidence}} <!-- 예: Supabase 로컬 캐시 레이어 적용 / 해당 없음 -->
- [ ] **실시간 리스너 범위 제한 + 해제, 목록 limit()+페이지네이션** — 리스너는 꼭 필요한
      화면·범위에만 걸고 화면 이탈 시 해제하며, 목록 조회는 `limit()`과 페이지네이션을 반드시
      쓴다. 구현 근거: {{item_2_evidence}}
- [ ] **집계 문서(counter) 패턴** — 카운트·통계는 문서 전체를 읽지 않고 별도 집계 문서로 관리한다.
      구현 근거: {{item_3_evidence}}
- [ ] **로컬 캐시 + TTL 우선** — 원격 데이터는 로컬 캐시를 우선 사용하고(예: TTL 24h), 네트워크
      호출은 캐시 미스·만료 시에만 발생한다. 구현 근거: {{item_4_evidence}}
- [ ] **이미지 최적화** — 업로드 전 클라이언트 리사이즈, 다운로드는 캐시 라이브러리를 경유한다.
      구현 근거: {{item_5_evidence}}
- [ ] **정적 콘텐츠 번들** — 설정·정적 콘텐츠는 서버 조회 대신 앱에 번들하고 업데이트로만
      갱신한다. 구현 근거: {{item_6_evidence}}
